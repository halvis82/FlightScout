# FlightScout audit, 2026-09-26

Three audits (website in every state, engine + CLI + MCP, and a review of the day's changes), plus a seller
check and live testing. Every finding, what was done, and where it stands. ✅ fixed and verified, ⚠️ needs an
outside action, ❌ not possible.

## Security

| Finding | Status |
|---|---|
| `/login?next=` ran scripts and redirected anywhere (also `/.//evil.com`) | ✅ only paths on this site; unit tests |
| Places PATCH wrote any column (could move a place into another account) | ✅ whitelisted, validated fields |
| Server errors leaked SQL and user ids | ✅ generic message, details in the log |
| Extension answered any `*.vercel.app` page | ✅ only the real site and localhost (v1.1.1) |
| Local runner open to DNS rebinding | ✅ only requests addressed to 127.0.0.1/localhost |
| Engine ran open when ENGINE_KEY was unset; key compared in non constant time | ✅ refuses without a key, `hmac.compare_digest` |
| API tokens could mint tokens that outlive revocation | ✅ child tokens revoked with their parent |
| Owner's email hardcoded as the signup allowlist default | ✅ no default (unset = nobody) |
| Push subscriptions accepted any URL | ✅ browser push services only |
| Alert emails unescaped | ✅ escaped, sent after the response with a timeout |
| Sign in limits in memory (weak on serverless) | ✅ stored in the database |
| New accounts could claim an allowlisted address they don't own | ✅ code: email confirmation. ⚠️ active once `RESEND_API_KEY` and `ALERT_FROM_EMAIL` are set in Vercel |
| Fare hints showed which routes people search | ✅ signed in users only |
| Unverified agencies (HolidayBreakz and others) passed through by metasearch sites | ✅ hidden by default, Settings can show them flagged |

## Features and performance added

* ✅ Smart routes scan: layovers from real fares at both ends, fare memory (engine and website), Kiwi leg matrices, nearby airports, airline re-pricing, detour filter.
* ✅ Multi city and trip builder legs from more sources; trip builder travelers field.
* ✅ Ryanair source; 18 airlines added to the directory (145); 764 small airports.
* ✅ MapLibre no longer loads on pages without a map (544 KB to 261 KB of scripts on Settings).
* ✅ Extension searches send each Google page once.
* ✅ Hourly catch up of deploys skipped by Vercel's daily limit.
